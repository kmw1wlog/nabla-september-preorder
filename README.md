# NABLA September Mock Preorder Concepts

## Landing

문제지·해설·패키지를 함께 보여주는 구성 중심안을 최종안으로 사용합니다.

이 저장소는 기존 학원용 사이트와 완전히 분리하여 운영하는 NABLA 브랜드 사본입니다.

학원·강사용 9월 모의평가 반영 무료본·사전예약 비교 페이지입니다.

## 비교 버전

- A안: 결제 없는 8·16·24부 수량 확보 후 PDF 즉시 다운로드
- B안: 5,000원 예약금 흐름 후 PDF 다운로드 (로컬 시안에서는 실제 청구 없음)
- C안: 이메일 입력 후 PDF 다운로드, 완료 화면에서 사전예약 제안

## 보존 기준

- NABLA 저장소와 배포 프로젝트는 기준 사이트에서 완전히 분리해 운영합니다.

## 확정 정보

- 한정 수량: 1,800부
- 신청 기간: 8월 21일~8월 30일 선착순
- SECTION 1: 9월 9일 주문 마감, 9월 14일 출고
- SECTION 2: 9월 30일 주문 마감, 10월 5일 출고
- SECTION 3: 10월 21일 주문 마감, 10월 26일 출고
- 기본 단가: 1인 5,500원
- 인원별 할인율: 10%, 15%, 20%, 25%, 30%

## 로컬 실행

```bash
npm ci
npm run dev -- --port 4182
```

- A안: `http://127.0.0.1:4182/a`
- B안: `http://127.0.0.1:4182/b`
- C안: `http://127.0.0.1:4182/c`
- 기존 단체 주문: `http://127.0.0.1:4182/order`
